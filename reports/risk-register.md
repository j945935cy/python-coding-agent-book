# 風險清單

| 等級 | 風險 | 控制措施 | 門檻 |
|---|---|---|---|
| 高 | 模型產生危險命令 | Bash 限制模式、白名單／攔截、before Hook | 負向測試通過 |
| 高 | 路徑逃逸 Workspace | `Path.resolve()` 與祖先路徑檢查、符號連結測試 | 所有越界測試通過 |
| 高 | 截斷工具參數被執行 | 先判斷 stop reason，再拒絕整批工具呼叫 | 專門測試通過 |
| 高 | 無限 Agent Loop | `max_turns` 與明確錯誤結果 | 測試可終止 |
| 中 | 真實模型 API 使測試不穩定或產生費用 | 核心只用 `FakeModel` | pytest 不需 API Key |
| 中 | 上游 Pi 持續變更 | 記錄 Commit SHA 與查證日期 | 引用可追溯 |
| 中 | 平行結果順序錯亂 | 以原呼叫索引收集結果 | 順序測試通過 |
| 中 | 事件串流未正常收尾 | 統一 success/error/cancel finalization | 事件測試通過 |
| 低 | TypeScript 與 Python 概念混淆 | 每章標示原始設計／教學簡化／自行擴充 | 編輯稽核 |
| 低 | 書稿程式碼與實際檔案漂移 | 先改程式、測試後同步書稿 | 每章一致性檢查 |
